**Android 离线预览 0.1.0-preview.1，源码副本 v030。** 这是一份可安装的界面预览 APK，尚未达到 Windows 的全部功能。

基于 v025 安卓交互预览，保留双列自然高度目录、完整显示的钞票图片、筛选与详情页、正反面图片组、来源/网址填写和展示组切换。支持系统选择 JPG/PNG/WebP；深浅色跟随系统，可在预览中切换。评分支持选择及键盘输入，中国站和全球站切换在样例流程中演示。

**限制必须先看：** 官网实时查询与自动采集、完整 PMGX/整库导入导出尚未接入。上传图片组仅供本次预览，未持久化为正式藏品库；重启或重新载入后会重置。设置 JSON 不能代替图片和藏品备份。原图另存尚未接入时会明确提示。

使用独立包名 `io.github.yushendu224.pmglibrary.preview` 和项目专用测试签名，避免与未来正式版混用。源码提供构建脚本；发布前校验 APK 包信息、签名及 ZIP 对齐。尚未在小米 15 实机安装验收，不承诺实机表现已验证。

本项目由 OpenAI Codex 辅助开发；应用界面不显示 AI 声明。独立项目，与 PMG 无隶属关系。测试签名私钥、个人图片和设备数据不在仓库或源码包中。
