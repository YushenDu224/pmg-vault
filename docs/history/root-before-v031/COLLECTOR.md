# v016 查询与采集使用说明

1. 启动后默认进入“库”，使用搜索、筛选、升降序或卡片/表格查看档案。
2. 点击侧边栏“查询与采集”或顶部“查询钞票”，进入独立页面。
3. 选择中国/全球站，输入评级号码及评分，点确定。官网和采集结果在当前页面显示。
4. 必要时手动完成官网验证。查询会话在切到库时保留，官网原生视图随页面隐藏。
5. 返回“库”直接看到目录，无需向下滚过查询区。详情保留原图、原文、网页截图、快照及 11 项检索字段。

首次安装：Node.js 22+，在 versions/v016-separated-pages 运行 npm install、node node_modules/electron/install.js、node launch.mjs。浏览器和桌面库相互独立，可通过整库 ZIP 导入迁移。
