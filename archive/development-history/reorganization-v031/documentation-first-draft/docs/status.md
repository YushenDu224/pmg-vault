## Windows

0.18.0 包含独立查询与采集、库、检索筛选排序、回收站、原图和网页存档、PMGX/整库备份，以及上传正反面图片组、来源网址和展示组选择。安装包自带所需运行环境，未数字签名。

已知内嵌官网在部分 Cloudflare 流程可能反复验证，0.18.0 没有后续浏览器及状态同步修正。新 Windows 测试版保留原主题，加入窗口外壳、浏览器兼容性与采集反馈同步调整。

历史 v029 有 41 项回归及运行文件核对记录，无推送情况下的离线真实 UI 同步曾通过。v027 曾实际保存官网详情、两张原图及网页档案；随后外层状态反馈滞留的修正进入 v028。v028 最后一轮真实官网复测未完成，所以不能称为 Cloudflare 人工验证循环已经全面解决。

源码检查、打包成功不代替安装升级和在线真人流程验收。Windows 测试包沿用同一资料库设计，安装目录不同不自动隔离用户数据；安装前请导出整库备份。仓库整理不读取、迁移或删除私人藏品。

## Android

可体验双列自然高度目录、完整图像预览、深浅主题、系统选择 JPG/PNG/WebP、来源及网址记录、图片组和展示组切换、样例查询流程及设置 JSON 导出。

限制：

- 中国/全球选择演示样例流程，没有实时官网请求或自动采集。
- 网页快照、完整 PMGX/整库 ZIP 导入导出和原图另存尚未接入。
- 上传图片和编辑内容只在本次预览内存中，退出、重载或进程回收后会丢失；设置 JSON 不包含图片，不能作为藏品备份。
- APK 使用独立包名及项目专用测试签名，签名私钥不进入源码仓库。
- 包信息、签名、ZIP 对齐和静态资产核对通过；Lint 记录为 0 错误、4 警告。没有小米 15 或其他真机安装及交互验收。

完整细节见 [Android README](../apps/android/README.md)。Android 当前不能替代 Windows 私人藏品库。
