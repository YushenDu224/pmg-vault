# v004 实现状态

PMGX 实现版本为 1.0，具体读写契约见 lib/archive.mjs。继承的 FORMAT.md 是历史草案，结构意图保留；实现支持 JPG/PNG/WebP 原图，截图可为 JPG 或 PNG，MHTML 为可选资源。checksums 校验每个 payload；不执行导入代码。ZIP 使用标准 store 导出，支持 store/deflate 导入。

v002 保留初次实现和失败测试；v003 修复 ZIP 文件头与静态资源路径；v004 限制原图媒体类型并增加启动说明。

界面验证：真实样例导入、列表、详情原图、网页隔离快照、无结果搜索、表格和排序方向。图片下载与网页导出是本地档案功能，在线自动采集尚未实现。实际手机设备与 Electron 安装包未验证。

当前存储采用 IndexedDB 单记录事务，图片字节随档案保存在该记录中；适合主体试用，后续独立资源仓库与 SQLite 属于下一阶段。合并采集保留历史文件；重名资源不一致时拒绝导入。尚未支持非数值评分、直接导入整库 ZIP、人工修正正反面或自定义标签编辑。
