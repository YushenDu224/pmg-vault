# PMG库 v007 · 藏品删除与官网视觉统一

从 v004 完整目录副本调整界面，保留全部历史副本。移除宣传横幅，替换为官网风格的“检验PMG评级”表单，项目显示名称改为 PMG库。

## 启动

需要 Node.js 22+，无需安装依赖。在本目录执行 `node server.mjs`，打开 http://127.0.0.1:8790 。支持桌面和手机宽度布局。

已实现：IndexedDB 本地藏品库、真实样例导入、卡片/表格、八字段检索与升降序、组合筛选、原图查看/下载、截图与隔离网页快照、历史记录、PMGX v1 ZIP 导入导出、同编号历史合并与整库 ZIP 导出。

原图与存档保存在浏览器资料库中，不发送到云端。清理浏览器数据前务必导出 PMGX 或整库 ZIP。换设备可导入各个 PMGX；整库 ZIP 目前需解压后批量选择 PMGX 导入。

查询页支持中国/全球网站选择和准确官网跳转。**自动浏览器采集、验证码接续、Electron 安装包和原生手机应用尚未实现**。本版目标是可运行的软件主体，不代表采集引擎已完成。

样例是此前人工核实记录；运行 `node scripts/build-sample.mjs` 会从项目外 outputs 已保存资料生成 `PMG-8077301-001.pmgx`。软件缺少该文件时仍可导入自己的档案。个人样例与原图不纳入源码版本。

`node --test tests/core.test.mjs` 验证档案、损坏拒绝、排序、站点映射；`node scripts/check.mjs` 验证封存。未进行真实手机设备、安装包或新在线查询采集测试。

模块：lib/domain.mjs 数据规则，lib/archive.mjs ZIP/PMGX，lib/storage.mjs 持久化，ui/app.mjs 页面，ui/theme.css 主题。UI 不解析官网 HTML。导入上限 96 MB、512 文件；首版只接收数字评分。来源网页不受信任，在禁用脚本和外部请求的隔离视图查看。

## v006 启动修复

从封存 v005 复制，在新副本修复启动顺序和服务生命周期。双击 `启动PMG库.cmd`：先启动本机后台服务，等待就绪，再打开浏览器。启动窗口退出不会关闭服务。电脑重新启动后再次双击即可，不增加系统自动启动项。

服务只监听 127.0.0.1:8790；健康检查为 /api/health。重复启动同一版本会复用服务。日志在项目根目录 user-data/runtime，独立于源码版本。其他版本占用端口时提示用户关闭，不自动结束未知进程。
