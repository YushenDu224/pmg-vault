首个真实样例：PMG 8077301-001 / 67，序列号 S51786112C。中国站和全球站均已人工查询过，但此前采集操作不是本项目已实现的自动化功能。

发布验收明确区分：本地代码检查、自动化浏览器检查、真实官网采集、手机端检查和安装包实测。未完成的检查必须保留为未完成。
