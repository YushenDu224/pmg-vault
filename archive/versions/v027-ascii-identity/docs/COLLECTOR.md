# 内嵌官网自动采集

本版在 Windows 使用 Electron WebContentsView 承载真正的 PMG 官网页面，位于应用的桌面采集窗口右侧。不是 iframe，也不会把官网代理到本机或关闭网页安全限制。

## 使用

1. 双击输出目录的“启动PMG库.cmd”，进入“查询与采集”。
2. 选择中国站或全球站，输入编号（8077301001 或 8077301-001）和数字评分，再点击查询按钮。
3. 在打开的采集窗口中操作官网。需要人机验证时自行完成；程序会等待，不会自动破解验证。
4. 匹配编号和评分、详情连续两次稳定后，自动保存原图、文字、截图、离线 HTML 和 MHTML。保持资料库网页打开，档案会自动入库。
5. 接着查另一张时，在同一个采集窗口左侧输入新条件。失败时可重试；部分资源失败会明确标记，不能当作完整采集。

一次查询保存一次，避免网页轮询不断生成重复档案。再次查询会产生新的采集历史，保留旧资源。官网确实没有图片时保存文字与网页，资料库使用已有的文字及占位预览。

## 安装与运行

本机已安装运行依赖。其他电脑需 Node.js 22+，在本版本目录执行：

```sh
npm install
node node_modules/electron/install.js
node launch.mjs
```

也可使用 pnpm install --frozen-lockfile，再运行 Electron 安装脚本。源码包不捆绑体积较大的运行依赖。尚未制作独立 exe 安装包；手机或普通网页不能直接运行桌面采集器，但可导入 PMGX 查看资料。

## 保存位置与备份

- user-data/inbox：完成的 PMGX 档案。
- user-data/captures：每次采集生成的原始 MHTML 中间文件。
- user-data/collector-profile：官网浏览会话，仅保存在本机。
- 浏览器 IndexedDB：日常藏品与索引；请通过导出 PMGX 或整库导出备份。

这些目录位于 pmg-vault 根目录，不放在封存源码中；源码归档及 GitHub 上传均排除个人数据、会话和运行依赖。不要只备份源码来代替藏品备份。
