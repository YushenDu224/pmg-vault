# v020 / Windows 0.16.2：取消固定导入上限

本版本复制已核实封存的 v019-windows-installer，继续采用 v016 的页面和配色。v017/v018 图片分组设计原型未引入。

## 行为

- 取消单文件 96 MiB、ZIP 解压总量 96 MiB、整库 200 张及 ZIP 512 个资源条目的固定上限。
- 支持普通 ZIP 和 ZIP64 输入。File/Blob 随机读取目录，整库逐张读取 PMGX、校验和保存，不先将整个备份转为 ArrayBuffer。
- 显示已导入张数。过程中禁用再次导入；成功和失败后恢复按钮。失败会显示已保存数量，重试会合并和去重已存在的采集。
- 继续拒绝路径穿越、重复路径、资源重叠、非法索引、加密或不支持的压缩方式；继续验证解压声明长度、CRC32、SHA-256、PMG 元数据与采集冲突。
- 自动升级备份读取也移除固定 96 MiB 检查。

“无固定大小上限”指不设置应用级 MB/GB 限额，不代表设备资源无限。单张 PMGX 的资源和 IndexedDB 读写仍使用内存；浏览器存储配额、磁盘容量、ArrayBuffer 和 JavaScript 精确整数范围决定实际可处理大小。现有导出器仍是内存型 ZIP32，超大型导出另需流式 ZIP64 写入器。

## 数据与回档

沿用应用标识、`pmg-library://app/` 源、数据库版本与 `%APPDATA%/PMG库/profile`。升级不做数据库结构迁移。安装路径仍可自选。卸载不自动删除个人数据。升级前导出备份；保留旧安装包和 v019 源码副本。

## 验证范围

自动化覆盖超过 96 MiB 的 PMGX、201 张整库、600 个资源、切片读取、4 GiB 以上 ZIP64 目录偏移、ZIP64 entry 扩展、压缩长度与 CRC 错误、重复索引；保留全部历史回归测试。大于 4 GiB 的偏移使用稀疏虚拟 Blob 验证寻址，没有宣称实际导入数 GB 的个人藏品。

25 项自动化测试全部通过。真实桌面备份仅用于本机隔离验收，不包含在源码或安装包中：154,906,697 字节（约 148 MiB）的备份通过实际文件选择控件导入，显示 6 / 6；再次导入仍为 6 张藏品、9 条采集记录，64 个资源条目全部匹配源 SHA-256，页面重新载入后数据仍在。正式资料库未用于该项测试。
