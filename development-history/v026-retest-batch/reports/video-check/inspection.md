# 已保存录像的离线画面核查

核查对象：`recording/pmg-app.webm`。本次未抓取屏幕、未录制新视频、未访问外网、未操作当前运行的 PMG 应用。只使用独立且隐藏的本地 Electron 解码窗口，以 HTML video + canvas 从原文件提取画面。

## 结论

**3、40、90 秒的三张抽样帧均为 PMG库自身的“查询与采集”界面，内嵌 PMG 全球站 Cloudflare 安全验证页；没有出现 Codex 或其他应用。** 因此已保存录像至少在这些采样时刻捕获到了预期应用，而不是被遮挡的 Codex 界面。

这只是三处解码抽样，并非逐帧检查整段录像。三张图没有直接记录“人工点击 → 验证转圈 → 重置”的完整过程；不能凭抽样帧宣称所有点击均已录到、120 秒每一帧均有效，或确定验证循环原因。也未把 start metadata 的窗口名当作画面有效性的唯一依据。

## 可复用提帧代码

- `extract-main.cjs`：独立隐藏窗口、仅允许 file/data/blob 请求、校验本地调用、写入三张 PNG 并核验原文件哈希。
- `extract-preload.cjs`：受限的本地解码消息桥。
- `extract.html` / `extract-renderer.js`：本地 video 解码、寻址和 canvas 输出。
- `classify-local-frames.ps1`：Windows 自带离线 OCR 预检；只输出预定义应用/验证标识计数，不输出或保存完整识别文字。先确认 PMG / Cloudflare 标识且未检出 Codex，再对三张 PNG 做视觉核查。

代码保留在此目录。正常桌面执行环境下，用已有 Electron 45.2.2 启动 `extract-main.cjs`，启动方式必须保持隐藏窗口；不能把此工具改作屏幕捕获。工具拒绝覆盖已有 PNG 与解码报告，重复实验应先复制工具到另一个独立目录并明确新的输出目标。
