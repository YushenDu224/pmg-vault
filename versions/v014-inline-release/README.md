# PMG库 v014 · 一体化查询与完整详情

绿色“检验PMG评级”区域集成查询表单、官网交互、采集状态、结果预览、完整字段、重试和导出；侧边栏“查询与采集”保留并打开同一工作区。桌面窗口统一承载官网与本地藏品库。

详情与采集结果均显示 11 个字段：PMG 编号、名称、目录号、冠字号、国家/地区、分数、评级日期、钞票年份、印章类型、签名、评论。缺失值显示“不适用”，使用现有 PMG 官网标题字体栈；底层仍保留 null 或未定义，不把占位文字写回原始资料。所有字段支持独立检索及升降序，缺失值排序置后；点击“不适用”可筛选该字段缺失的藏品。

双击启动脚本默认打开一体化桌面主窗口。需要 Node.js 22+ 与 Electron 45.2.2；其他电脑先 npm install，再 node node_modules/electron/install.js。使用 node launch.mjs --web 可保留普通浏览器资料管理方式，浏览器内查询会唤起一体化桌面窗口。

桌面与浏览器具有独立的 IndexedDB。切换前先在原浏览器导出整库 ZIP，然后在桌面主窗口通过“导入档案”直接导入此 ZIP。原浏览器资料保留不变。运行数据仍在项目 user-data，源码不包含会话和个人藏品。

本版由封存 v012 完整复制，v012 由 v011 复制；v011 从 v010 复制完成首次一体化改造。每步完整源码副本均保留。

自动化测试：node --test tests/*.test.mjs。正式验收结果以项目根目录 CURRENT.md 为准。

## v014 升级恢复
若本机 user-data/migrations/v014-browser-library.zip 存在，桌面资料库首次启动会校验并合并该整库备份，成功后记录完成标记；不删除原备份，不覆盖浏览器原库。固定备份路径只对本机主页面提供，官网无此接口。缺少升级备份时仍可通过“导入档案”手动导入 ZIP。v011～v013 是本次改版的完整开发副本，v014 为包含升级恢复的交付版本。
