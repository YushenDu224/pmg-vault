# PMG库 · 图片分组交互原型

v017-image-groups-prototype 是从通过封存检查的 v016 完整复制的方案副本。正式入口仍为 v016；本版新增内容只位于 prototype/image-groups，不迁移正式藏品。

运行：在本版本根目录执行 `node prototype/image-groups/serve.mjs`，访问 http://127.0.0.1:8861/ 。默认详情页为 8077301-001，初始一组官网样例和一组明确标注的上传布局样例。只使用已保存的本地官方样例，不发起新的官网查询。

## 交互

- 按官网、自行上传筛选分组；每组各有正反面位置，缺图标“未上传”。
- 右侧编辑面板选择或拖入 JPG/PNG/WebP，限每张 20MB，可交换正反面。至少一面即可保存。
- 每组记录名称、来源名称、HTTP/HTTPS URL 和备注。URL 只作链接，不下载目标内容。来源可选，不凭空推断。
- 使用独立 IndexedDB `pmg-image-groups-prototype-v1` 保存 Blob 和元数据，刷新保留；未保存编辑可取消。
- 图片查看器可按原始尺寸查看、切换两面、下载原始文件。演示 ZIP 包含原图及 image-groups.json，尚非正式 PMGX。
- 响应式布局：桌面两面并排，手机纵向排列，上传面板全屏。系统字体栈与 v016 相同，深绿 #053d22、白 #fff、浅灰 #f5f5f5、深灰蒙版。

## 正式功能接入建议

独立 imageGroups 模型包含 id、kind、noteId、captureId（官网组）、name、sourceName、sourceUrl、notes、frontResourceId、backResourceId、createdAt、updatedAt。图片资源使用内容 SHA256，保留原始字节、文件名、MIME 和尺寸。正反面由用户指派，不按 OBV/REV 猜测。相同文件可复用存储，分组、来源和时间各自保留。

官网组不可由上传表单覆盖；新官网采集生成新组。上传修改保留历史修订。正式 PMGX 采用可选 imageGroups 扩展，兼容旧档案由资源和采集记录生成展示分组，先备份再迁移副本。查询引擎、存储与 UI 不相互解析 DOM。

目前是供评审的交互方案，未接入正式库和 PMGX 读写，也未做真实手机设备验证。正式库、回收站与查询模块均不受本原型影响。


## v018 展示组

从已验证封存的 v017 完整复制。每组均有“设为展示组”，当前组绿边、标记“当前展示组”。“展示设置”提供详情页正反面与库卡片预览，“当前展示”筛选仅看选中组。偏好以 noteId 为键独立保存在当前浏览器，导出 ZIP 的 JSON 记录 preferredImageGroupId。

选中单面组时不从其他组补图；卡片优先正面，否则用本组背面。偏好失效或所选组没有图片时回退官网组，再回退第一个可用组。这是原型演示，正式 v016 不受影响。
