档案资料

官网认证字段与自行上传图片的来源信息分别保存。

图片分组方案

延续既有主题，让每一组图片都能追溯来源。

01

一组，两面

官网采集与自行上传分别成组。正面、背面有明确位置，允许只上传一面，另一面标注“未上传”。每次可继续补充新组。

02

来源属于这一组

上传时填写组名、来源名称、URL 与备注。来源和 URL 可留空，界面明确显示未填写；网址只作为溯源链接，不自动下载网页内容。

03

原图独立留存

展示预览不会改写原文件。可放大和下载原图；正反面由用户选择，不根据文件名猜测。官网组与上传组分开编辑。

04

接入现有档案

正式实现建议增加 imageGroups 模型，通过资源 ID 关联正反面及采集记录，兼容原有 PMGX。此原型的保存与 ZIP 导出独立于正式藏品库。

展示组选择

官网图片或任一自行上传组均可设为展示组。详情页默认使用整组选定图片，库卡片优先使用本组正面、缺少正面时使用本组背面；缺少的一面保持空缺，不与其他组混用。选择保存在当前浏览器，导出时也记录展示组 ID。

可操作范围

添加、编辑、补图、交换正反面、来源筛选、放大查看、原图下载及独立 ZIP 导出。已上传图片在此浏览器刷新后保留。手机尺寸下图片纵向排列，编辑面板转为全屏。
