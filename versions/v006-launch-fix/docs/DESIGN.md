# 需求、架构与界面基线

日期：2026-11-05。状态：已接受的产品方向，以下功能待实现。

## 使用方式

Windows 桌面端完成在线查询与采集；响应式网页/PWA 在电脑和手机导入、浏览档案。第一版不承诺手机浏览器独立采集官网。后续远程采集服务是单独扩展，不影响离线档案格式。

用户输入编号和评分，自选中国站或全球站。工作流：打开所选站点 → 查询 → 处理必要的人工验证 → 检查编号和评分 → 提取原文 → 下载原图 → 保存整页 PNG、网页存档及静态副本 → 完整性检查 → 原子写入藏品库。

采集状态分为 queued、loading、needs-user、matched、not-found、partial、failed。not-found 只接受官网明确的无结果提示。验证页、403、加载空页和超时均不能推断为无记录；错误评分不能触发删除。

## 模块边界

建议采用 TypeScript：Electron 桌面外壳、浏览器采集引擎、响应式 PWA。具体 UI 框架在 UI 阶段决定。

| 模块 | 职责 | 禁止依赖 |
| --- | --- | --- |
| domain | 统一钞票、采集、资源模型与字段定义 | DOM、Electron、UI 框架 |
| adapters | CN/Global 页面字段及原图链接解析 | 卡片布局、主题 |
| collector | 浏览器状态、截图、网页存档、下载编排 | 具体页面组件 |
| archive | PMGX 导入导出、版本、资源校验 | 官网 DOM、UI 框架 |
| library | 数据持久化、索引、检索、排序 | 页面样式 |
| ui | 展示、输入、任务状态和主题 | 官网解析规则 |

桌面可使用 SQLite，网页端使用 IndexedDB；两者遵循相同数据与查询协议。个人图片单独保存，用内容 SHA256 去重。数据库可重建索引，外部 PMGX 才是携带、交换单位。

## 字段与检索

必须支持逐字段查询、组合筛选和升降序：PMG 编号、名称、目录号、冠字号/序列号、国家/地区、分数、评级日期、钞票年份。

附加字段：币种、面额、EPQ 等标识、采集站点、保存时间、是否有原图、自定义收藏标签。关键字段是可索引的类型化数据，不仅是自由文本标签。

编号与冠字号为字符串。分数保存数字值、标识及原始展示值。年份与评级日期分开；无年份、ND 或跨年范围保留原文，年份提取记录依据与可信度。未知值不猜测。

文字使用统一规则的自然排序，数字用数值排序，日期用标准日期排序；缺失值在升降序均排末尾，最后以稳定 ID 打破同值排序。国家保存原始值与标准化代码。中文、英文站字段需映射到同一模型。

## 界面

主题建议：深绿 #173D2A、暖白 #F7F6F0、浅灰 #E8ECE7、点缀金 #B49A58。颜色、间距、字号、圆角统一为主题变量。表格列与筛选器来自字段注册表。

- 查询页：站点切换、编号、评分、验证区域、逐项保存状态与失败重试。
- 藏品库：卡片/表格切换，全局搜索，字段过滤，排序字段和方向，导入/导出。
- 详情页：原图查看、结构化标签、原始文字、网页截图、静态快照、历史采集。
- 手机：单列卡片、底部筛选面板；图片/信息/存档/历史标签页。

预览优先级：确认的正面图 → 唯一可用原图 → 已核实官网占位资源与文字合成 → 本地文字占位卡。合成图明确标为占位预览。占位资产的具体来源与使用方式须在实现时核实，不凭空生成官网占位图。

本次真实样例中，官网 OBV 文件显示钞票背面，REV 文件显示正面。保留来源标记与实际画面方向两个字段，允许人工修正；不自动把所有档案反转。

## 数据保护

更新查询新增 capture，不覆盖旧采集。部分保存标明具体缺失项，保留可恢复中间状态。文件导入限制解压大小、文件数量和路径，拒绝路径穿越，检查哈希。静态网页使用隔离视图，默认禁用脚本、表单及外部自动请求；MHTML 作为可导出原始存档，不强求手机原生渲染。
