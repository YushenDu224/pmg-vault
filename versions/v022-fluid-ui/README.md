# PMG库 · 连续曲率界面 0.19.0

源码副本 v022-fluid-ui，从核实封存的 v021 完整复制。新界面使用连续曲率圆角、浅灰绿色侧栏与深绿操作按钮，原生窗口按钮融入页面顶栏。手机布局采用底部导航和上拉详情。

## 使用

运行输出目录中的 PMG-Library-0.19.0-Setup-x64.exe，选择安装范围和安装目录。安装后从桌面或开始菜单启动。安装包内含所需运行环境。顶部空白区域可拖动窗口，右上角提供最小化、最大化/还原和关闭。

在库中打开藏品，点击“添加图片组”，选择正面或背面图片并填写可选的来源、网址和备注。每组至少一面，可编辑和替换已上传的图片。点击“设为展示组”后，详情和卡片使用同一组。背面单独成组时，卡片使用该组背面。

新增图片和展示选择随 PMGX 与整库 ZIP 保存。旧档案可以直接导入。合并同一藏品时保留本地展示选择，按更新时间合并图片组。官网原图和采集历史仍可查看。

用户数据位于 %APPDATA%/PMG库，与程序安装位置分离。旧开发版通过“导出整库”生成 ZIP，在安装版“导入档案”中导入；保留旧库和备份。卸载配置不自动删除数据。

## 重建

开发环境 Node.js 22+、pnpm。安装 pnpm-lock.yaml 锁定依赖，执行 node node_modules/electron/install.js 和 node scripts/make-icon.mjs；运行 npm run dist:win。构建配置可通过 PMG_ELECTRON_DIST 指定 Electron 45.2.2 目录。源码开发入口 npm start。详细架构见 docs/WINDOWS-INSTALLER.md。

本版取消导入文件、解压总量、整库张数的固定上限；使用 File/Blob 按张读取 ZIP/ZIP64，保留 CRC、SHA-256、路径和重复项验证。设备内存和磁盘容量仍构成实际限制。中途遇到损坏文件会保留已经导入的藏品，重试自动去重。详见 docs/UNLIMITED-IMPORT.md。

26 项回归测试通过。Windows 打包程序在隔离资料库中通过公开旧档案导入、图片组表单打开、原生最大化/还原、最小化调用和关闭验证。按 400×890 与 402×874 逻辑视口检查库页、详情页、底部导航、页面互斥与横向溢出。预览图在版本外 previews 目录，手机真机尚未测试，安装包未签名。

## 三端实施方向

共用 domain、PMG 字段适配器、图片组模型与 PMGX 读写模块，以及响应式页面。平台桥接单独处理窗口、文件、图片选择和官网采集。Android 需要原生 WebView、会话下载、网页存档与截图桥接。iOS 对应 WKWebView、WKHTTPCookieStore、URLSession、网页存档和截图。所有端保存共同的 PNG 和静态 HTML，并在 PMGX 中保留不同系统的原始网页存档类型。

Android 与 iOS 原生工程和安装包在本版本尚未生成。此处手机截图用于布局评审。iOS 原生包需要 macOS/Xcode 构建和签名，TestFlight 分发需要 Apple Developer Program。移动端大量原图的存储需要文件和索引分离，以降低 getAll 读取整库造成的内存压力。
