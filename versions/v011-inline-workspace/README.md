# PMG库 v010 · 内嵌官网采集

本版新增 Windows 桌面采集窗口，官网直接嵌入窗口右侧。完成必要验证后自动保存详情、官网原图、整页截图、离线 HTML 和 MHTML，并自动导入本地藏品库。支持中国/全球入口选择。回收站弹窗蒙版改为深灰。

[使用、安装、保存位置与实际验收](docs/COLLECTOR.md)

已保留检索筛选、升降序、卡片/表格、原图查看、PMGX 导入导出、整库导出、软删除和恢复功能。需要 Node.js 22+ 与 Electron 45.2.2；本机运行依赖已就绪，双击启动脚本即可。

采集能力目前面向 Windows，尚无独立安装包和原生手机端。中国站真实样例已通过完整采集；全球站在线验收尚未完成。

## AI 辅助开发声明
本项目使用 OpenAI Codex 等 AI 工具辅助设计、编写和验证。功能以实际验收结果为准。独立开发，与 PMG 无隶属关系。应用界面不展示 AI 声明。

官网配色及 logo 来源：https://www.pmgnotes.cn/ 。主题、页面、采集适配与档案格式分别维护。
